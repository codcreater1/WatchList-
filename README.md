WatchList 📺

WatchList is a simple C++ console application to manage your movies and TV shows. You can add media, filter by genre, and track whether you have watched it or not.

Features

Add movies or TV shows with title, genre, year, and watched status.

Show all media in the list.

Filter media by genre.

View only watched or unwatched media.

Console-based, simple and easy to use.

How to Use

Clone the repository or download the source code.

Compile the C++ program using any compiler (e.g., g++):

g++ -o WatchList WatchList.cpp


Run the program:

./WatchList


Use the menu to add, view, filter, and manage your media collection.
